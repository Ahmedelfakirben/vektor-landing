Kiosk Labs

Navegador Quiosco & Bloqueo de Sistema

Convierte cualquier smartphone o tablet Android en un comandero de camareros o terminal de autoservicio blindado. Impide que empleados o clientes abandonen tu software web, desactiva la barra de notificaciones y resiste reinicios.

  • ✓ Bloqueo Lock Task Estricto: Inhabilita botones Home, Recientes y gestos del sistema.
  • ✓ Inmunidad a Reinicios: Autoarranque prioritario al encender el terminal (`BootCompleted`).
  • ✓ Pantalla de Reposo (Wake Lock): Interfaz elegante con reloj en vivo, batería y estado WiFi/Offline.
  • ✓ Hardware & WebRTC: Auto-concesión de cámara para lectura de códigos de barra sin permisos manuales.
  • ✓ Gesto Secreto de Salida: 5 toques en la esquina superior derecha despliegan el PIN de administración (1234).
  • ✓ Bridge JavaScript: Compatible con `window.Kiosk` y `window.fully` para telemetría y control web.

Imprenta Labs

Agente Nativo de Impresión Térmica Directa

El puente local más ligero y rápido para conectar cualquier ERP, TPV o sistema web con impresoras de tickets (ESC/POS), cajones portamonedas y comanderas de cocina en red, sin runtimes pesados ni dependencias de Java.

  • ✓ Consumo Mínimo de RAM: Apenas ~14 MB en segundo plano (frente a 250 MB de QZ Tray).
  • ✓ Impresión Silenciosa Instantánea: Latencia menor a 50 milisegundos sin cuadros de diálogo.
  • ✓ Cola de Impresión Persistente: Si falta papel, los tickets se guardan y reintentan automáticamente.
  • ✓ Soporte ESC/POS & HTML: Renderizado directo de tickets a 58mm y 80mm con corte y apertura de cajón.
  • ✓ Impresoras de Red (Ethernet/WiFi): Envío directo a puerto 9100 sin necesidad de drivers Windows.
  • ✓ Integración Nativa Gastro & ERP: Listo para funcionar de serie con Vektor Gastro y sistemas web.

API & PROTOCOLO PARA DESARROLLADORES

Integra Impresión y Quiosco en Tu Propio Software

Ponemos nuestra tecnología a disposición de integradores, agencias y desarrolladores. Puedes conectar cualquier web, ERP o aplicación mediante JavaScript, TypeScript o WebSocket directo.

01 Impresión Térmica ESC/POS con JavaScript / TypeScript

Envía tickets formateados con corte automático, código QR de factura electrónica y apertura de cajón en 3 líneas de código:

ticket-print-example.js 
// 1. Conectar con el agente local Imprenta Labs (puerto ws://127.0.0.1:8765)
await imprentaLabs.connect();

// 2. Consultar impresoras disponibles en el sistema
const impresoras = await imprentaLabs.printers();
console.log('Impresoras conectadas:', impresoras);

// 3. Imprimir ticket estructurado ultrarrápido
await imprentaLabs.printTicket({
  printer: 'Impresora_Tickets_80mm', // O vacío para impresora predeterminada
  cut: true,                         // Corte de papel automático
  openDrawer: true,                  // Apertura de cajón portamonedas
  lines: [
    { t: 'text', text: 'RESTAURANTE EL PATIO S.L.', align: 'center', bold: true, size: 2 },
    { t: 'text', text: 'Calle San Juan, 14 - CIF: B-99887766', align: 'center' },
    { t: 'line', char: '=' },
    { t: 'cols', left: '1x Menú Degustación', right: '28.50 €' },
    { t: 'cols', left: '2x Copa Vino Ribera', right: '7.00 €' },
    { t: 'cols', left: '1x Tarta de Queso', right: '5.50 €' },
    { t: 'line', char: '-' },
    { t: 'cols', left: 'TOTAL IVA INCLUIDO:', right: '41.00 €', bold: true, size: 2 },
    { t: 'feed', n: 1 },
    { t: 'qr', data: 'https://verifactu.gob.es/factura/2026-0891', n: 6, align: 'center' },
    { t: 'text', text: '¡Gracias por su visita!', align: 'center' }
  ]
});

02 Impresión a Comanderas de Cocina por Red (Ethernet / Wi-Fi)

Envía comandas directamente a impresoras remotas por IP (puerto estándar 9100) sin necesidad de instalar drivers en Windows:

network-printer-example.js 
// Impresión directa a la impresora de cocina sin drivers
await imprentaLabs.printTicket({
  printer: { host: '192.168.1.180', port: 9100 },
  cut: true,
  lines: [
    { t: 'text', text: '--- COMANDA COCINA ---', align: 'center', bold: true, size: 2 },
    { t: 'cols', left: 'MESA: 12', right: 'CAMARERO: Alex' },
    { t: 'line', char: '-' },
    { t: 'cols', left: '2x Solomillo al Punto', right: '[MARCHA]' },
    { t: 'cols', left: '1x Ensalada César', right: '[PRIMERO]' }
  ]
});

03 Control del Dispositivo desde la Web con Kiosk Labs

Comunícate de forma nativa desde tu frontend web con el hardware Android:

kiosk-bridge-example.js 
// Compatible con API window.Kiosk y window.fully
if (window.Kiosk || window.fully) {
  // Consultar nivel de batería del terminal
  const nivelBateria = (window.Kiosk || window.fully).getBatteryLevel();
  console.log(`Batería restante: ${nivelBateria}%`);

  // Identificador de hardware único para licencias
  const deviceId = (window.Kiosk || window.fully).getDeviceId();

  // Síntesis de voz para alertas sonoras a camareros
  (window.Kiosk || window.fully).speak('Nuevo pedido recibido en Mesa 4');
}

💡 Tip Pro para Empresas: Activar Modo "Device Owner" en Kiosk Labs

Para evitar que los camareros o clientes puedan salir de la aplicación mediante cualquier combinación de teclas físicas o ajustes del sistema, puedes otorgar permiso de Device Owner por cable USB con un único comando:

ADB Terminal 
adb shell dpm set-device-owner com.kiosko.browser/.KioskDeviceAdminReceiver
